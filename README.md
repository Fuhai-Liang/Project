## 1) 决定县域健康水平的关键因素分析
**英文名**：Predictors for Better County-Level Health Outcomes  
**简介**：整合美国县级社会/环境/健康指标，建模并解释早逝率（age-adjusted premature mortality）的区域差异，输出关键决定因素与政策启示。  
**方法**：特征清洗与可视化 → 多模型对比（线性/树模型等）→ 重要性与因果讨论。  
**快速上手**：进入目录，按子 README/脚本说明加载数据并运行，或直接查看导出的报告（HTML/PDF）。

---

## 2) 基本类型识别
**英文名**：Handwritten Digit/Image Classification (28×28, 10 类)  
**简介**：对 28×28 灰度图的 10 类分类任务，比较 KNN、SVM、决策树与 Bagging；含归一化（MinMax）与 PCA。  
**亮点**：  
- 基线到进阶算法的性能与耗时对比  
- 超参数搜索与可重复实验配置  
**快速上手**：安装依赖后运行训练脚本，或查看报告获取结果对比表与混淆矩阵。

---

## 3) 学生成绩预测
**英文名**：Identifying Failure Risk in Students  
**简介**：基于教育数据进行失败风险识别/成绩预测；包含特征工程、模型训练与可视化面板。  
**快速上手**：打开目录内 HTML 报告预览结果；如需复现，按说明安装依赖后运行 R 脚本。

---

## 4) 实时更新新油价信息并在地图实时显示
**英文名**：NSW Fuel Prices – Realtime ETL & Map  
**简介**：对新南威尔士州（NSW）官方 Fuel API 进行定时抓取；清洗合并站点与价格数据，输出标准化数据以供地图/仪表板使用。  
**要点**：  
- API 拉取 `stations`/`prices` JSON  
- 异常数据（如价格为 0 的 EV 记录）过滤  
- 产出标准 CSV（如 `data.csv`）  
**快速上手**：配置环境变量（API Key/Token），运行爬取脚本（如 `crawl_and_MQTT.py`）即可生成最新数据。

## 5) 数据分析1
**简介**：通用的数据清洗、EDA 与可视化脚本集合（缺失值处理、分布检验、相关性分析、主题化图表等模板），便于在新项目中复用。  
**快速上手**：参考目录内示例 Notebook/脚本，按需拷贝到你的项目。

## 6) 新南威尔士州油价分析
**英文名**：New South Wales Oil Price Analysis  
**简介**：从 NSW 数据门户抓取与整合历史油价数据；准备城市/邮编映射与油站经纬度（含少量手工补点），构建品牌与油品维度分析。  
**快速上手**：先运行抓取与清洗脚本，再打开可视化 Notebook/报告查看分城市/品牌的价格对比。

## 7) 贫穷酗酒药物滥用与死亡之间的关系
**英文名**：Poverty, Alcohol/Drug Abuse and Mortality  
**简介**：研究县级贫困率、阿片类处方/滥用与药酒相关死亡率之间的关联；包含分布检验、相关性与建模讨论，以及结论与局限。  
**快速上手**：按目录说明加载整理好的县级指标，运行模型脚本并复现论文式图表。

## 运行环境与依赖（General）

不同子项目依赖 **Python**（pandas / requests / scikit-learn 等）或 **R**（tidyverse / ggplot2 等）。请在各子目录的说明文件中查看具体依赖与运行步骤。  
- 爬虫/实时任务需在 `.env` 或系统环境中配置 **API Key/Token**。  
- 推荐使用 `conda` 或 `venv` 管理 Python 环境，使用 `renv` 管理 R 包。

**通用步骤**：
1. 克隆仓库：`git clone <repo-url>`  
2. 进入目标子目录并阅读该目录下的说明/报告。  
3. 安装依赖并运行脚本，或直接打开导出的 HTML/PDF 成果。
